# Contributing to the ISR Website

Thank you for helping improve the Islamic Society of RMIT website.

## Development home

Current development repository:

**AIMHM/isr-website**

Active development branch:

**ideas**

Do not push unfinished redesign work into another repository or production branch.

## Before committing

Run:

    cd frontend
    npm run isr:health

Then visually check the pages you changed on localhost.

## Public content

Keep public language student-facing and practical.

Do not expose internal:

- content ownership
- review timestamps
- approval workflows
- committee operations
- compliance checklists

## Prayer information

Prayer and Jumuah information is operationally sensitive. Only publish confirmed details.

If uncertain, direct students to ISR rather than inventing a location or facility detail.

## Student support

Public support pathways route through ISR.

Do not add external support organisations or university pathways without an explicit content decision.

## Membership

ISR membership is free.

## Review

A review should confirm:

- the change works locally
- mobile layout works
- keyboard navigation remains usable
- no private data was committed
- source-of-truth information remains accurate
- no production deployment is bundled into the change
